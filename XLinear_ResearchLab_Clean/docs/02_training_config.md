# 参数、实验协议与正式复现

## 集中配置

全部用户可调参数均位于 `configs/experiment.yaml`。`source` 控制上游版本，`runtime` 控制设备与变体公共参数，`experiment` 控制正式任务，`pilot` 控制小型工程测试，`profiles` 固定作者的每个数据集/预测长度训练参数。

官方原版复现若要公平，对照模型**不得**通过旧的 `benchmark.py` 启用 `AdamW`、`BF16`、梯度裁剪，或把 `t_ff` 强制与 `d_model` 相等。

| 项目 | 官方训练器默认行为 | 当前工程处理 |
|---|---|---|
| 模型 | 官方 XLinear `features=M` | 官方文件 Git blob 校验，改造在内存中注入 |
| 数据 | ETT 固定 12/4/4 个月，Weather 70/10/20 | 直接用官方 `data_provider` |
| 标准化 | 训练集 StandardScaler + 历史窗口可选标准化 | 直接用官方数据加载与模型 |
| Batch | 作者对应脚本 | YAML `profiles` 按数据集/预测长度锁定 |
| 优化器 | Adam | 不修改官方训练循环 |
| 学习率 | `lradj=type3` | 不修改官方训练循环 |
| 精度 | 默认 FP32（没有启用 `--use_amp`） | 当前只支持 FP32 正式任务 |
| 早停 | 验证 MSE | 保留作者原代码 |
| 测试 | 作者 `Exp_Main.test` 的 MSE/MAE | 原日志中解析 `mse:..., mae:...` |
| 多种子 | 默认先 2025 | 配置可扩展 2025/2026/2027 配对比较 |

## 任务级输出约定

`run.sh full` 使用**完整数据与作者原始训练器**，但只在该数据、该跨度对应的官方参数上训练。

`run.sh pilot` 把训练上限缩短成2轮，目的是检查代码是否能真正运行及日志文件是否生成。pilot 结果不能与论文表格对比，更不能混入正式 summary。

正式运行**不会根据测试结果选超参数**。如果需要对改造模块的额外超参数调节，应在独立开发集/验证集决定，再锁定最终模型进行测试。

新增指标请保存额外 CSV，不要修改官方 `mse/mae` 定义；新的诊断方法由新模块承担。
