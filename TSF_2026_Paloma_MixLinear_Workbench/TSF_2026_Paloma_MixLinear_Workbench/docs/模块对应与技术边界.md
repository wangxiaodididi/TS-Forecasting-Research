# 机制移植与接口审计

原始 Paloma：`X [B,L,C]` → 自带实例归一化 → `R=(X-Q) [B,C,L]` → `PhaseModulation` / `ConditionalFusion` → `hidden [B,C,D]` → `output_proj [B,C,H]` → 反归一化。固定 L=96、C=7、D=256，H=96/336。原始源码不会被修改，仓库独立副本会附加一个 `Model.forward` 代理。

| 变体 | 输入位置 | 新增输出 | 原始核心保留 | 不宜声称的能力 |
|---|---|---|---|---|
| pca_head | final latent [B,C,D] | [B,C,H] residual | 全部 | 不是 TStruct 原结构 Token 编码 |
| segment_head | final latent [B,C,D] | [B,C,H] residual | 全部 | 不复现 TimeMosaic Prompt/Encoder |
| timebase_residual | R [B,C,96] | [B,C,96] correction | 3周期参数、双残差分支、Head | 没有自适应周期选择；ETTm1 用子周期 |
| phaseformer_router | R [B,C,96] | [B,C,96] correction | 同上 | 不是 PhaseFormer 的多层完整模型 |
| seer_soft_replace | R [B,C,96] | [B,C,96] correction | 同上 | 不是原 SEER 硬筛选、全局 Token/Encoder |
| t3_alignment | R、Phase、Amplitude [B,C,96] | [B,C,D] correction | 原分支和 Head | 不是原 T3Time 多模态编码 |

## 评价规则

用原始 Paloma 的固定训练配置跑所有候选，不跨数据集改变训练步长或训练损失追结果。同一 seed 仅提供候选筛选证据；最佳候选需对验证样本上的选择结果固定后，再做多个 seed 和其它能源数据的正式验证。结果目录按任务、模块独立，避免 summary 丢行。任何模型的微小测试差异都不应立即视为稳定增益。
