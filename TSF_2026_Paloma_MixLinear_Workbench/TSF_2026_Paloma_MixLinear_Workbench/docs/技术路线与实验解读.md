# Paloma v6：预测信息路径的对照设计

## 为什么不继续微调 Gate

Paloma 用 `R=X−Q` 构造周期残差，并通过 PhaseModulation、ConditionalFusion 处理，结果直接相加后线性预测。之前 v2–v5 的独立改造大多在0.0%–0.4%左右变化，且不同数据集方向不一致（单项最大收益不能代表全场景优势）。因此本轮检验两个**不同信息通道**：历史编码内部的相位/幅度交流，以及由未来预测位置主动读取历史。

## 计算图与输入输出

三种变体共享未经修改的 Paloma 基准预测 `Y0`。新模块仅产生零初始化的修正：`Y = Y0 + ΔY`（或者在基准隐藏层添加零初始化修正）。严格没有未来标签参与 forward。

### V6-A：cross_branch_tokens

`R,Phase,Amplitude` 为 `[B,C,96]`，原始两个调制输出各为 `[B,C,256]`。以12步为一个时间 Patch，形成各8个有序 Token，两个分支分别得到 `[B·C,8,64]`。原始调制输出经映射进入各自 Token，从而使两条真实分支的摘要参与交互。随后分别计算 `Attention(P,A,A)` 与 `Attention(A,P,P)`，拼接后形成隐藏层修正 `[B,C,256]`，加到 `phase_impact + amplitude_impact`，再通过原始 Paloma 的预测头。

与 v5 `t3_alignment` 不同，本版是**双向**且纳入真实调制输出，而不是单向从原始残差拼接条件值。

### V6-B：future_query

每个未来48步预测段有一个独立可训练 Query：H96对应2个 Query，H336对应7个。历史序列按照12步形成8个有序 Memory Token，并联合编码 `R`、原始历史 `X`、周期模板 `Q` 与 Phase 参数。Query 由预测段嵌入和 Paloma 已学习的隐藏表示共同决定，然后通过 Cross-Attention 读取所有历史 Memory Token。每个 Query 产生对应48步残差预测，并加回原始 Paloma 预测。

与 v5 `segment_head` 不同：**不能退化为单纯把 `Linear(256,H)` 切成多个小 Linear**；每个未来段与过去不同 Patch 发生注意力交互。

### V6-C：branch_aware_future

未来48步 Query 同时向两个独立历史记忆发起检索：Phase-conditioned Memory 和 Amplitude-conditioned Memory。独立注意力读出后融合，再形成每个未来段的48步修正。它试图让阶段性未来需求和两条历史分支信息在预测过程中相遇。相比简单叠加 A+B，未来 Query 在同一预测任务下统一查询两条条件历史表征。

## 公平性和限制

- 此轮 `Original` 采用 v3 同种子同数据设置下的既有实测元数据，不重跑和不替换它的权重。
- 三个改造各自基于同一原始 Paloma 主干参数初始化，但各自需要重新训练全网，**不是仅训练 Adapter 的微调**。
- 模块间参数规模和计算量不同，结果对比要同时报告训练时间、整体 GPU 已使用显存峰值、模型参数量，不能只看一次 MSE。
- token 的跨注意力权重不能直接解释为因果关系或信息重要性的充分证据。
- v6 首轮固定一个随机种子2024用于候选筛选；如果有稳定改善，再做多种子与额外能源数据的独立验证。
