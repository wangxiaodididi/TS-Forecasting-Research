# Paloma 模型结构拆解（基于 TSTS13/Paloma，commit def3dfc6）

## 模型信息流

输入 `x: [B,96,7]` 与 `cycle_index: [B]`：

1. 使用每个样本的历史均值、方差做标准化；通道置换为 `[B,7,96]`。
2. 从三个周期长为 `cycle` 的学习表中按相位索引取出：周期模板 `Q`、`phase` 和 `amplitude`，均为 `[B,7,96]`。
3. `residual = x_input - Q_indexed`，形成依赖可学习周期模板的残差。
4. `PhaseModulation(residual,phase)`：分别投影出 cos/sin 支路，正交化后根据 `phase` 生成的角度旋转，再残差连接 + LayerNorm；输出 `[B,7,d_model]`。
5. `ConditionalFusion(residual,amplitude)`：以幅度条件产生 `scale(sigmoid)` 和 `shift`，对内容投影作仿射调制；输出 `[B,7,d_model]`。
6. 两个分支相加经过 `Linear+GELU`，加上原输入的 `input_proj` 线性直连。
7. `Dropout+Linear(d_model,pred_len)` 输出 `[B,pred_len,7]`，再反标准化。

值得注意的实现细节：官方 `query_proj` 被初始化但在当前 `forward()` 中未调用。这是代码层面的未使用参数，不应把它叙述成模型实际执行的查询模块；`PhaseModulation` 和 `ConditionalFusion` 的 `hidden_dim` 形参也没有实际参与层维度的设置。

## 功能假设与验证逻辑

- **周期模板 Q**：有助于剔除可预测的固定相位分量。但当相位/周期漂移时，固定模板可能产生失配。`no_template` 是第一道证据。
- **相位调制**：用于表达残差随周期相位的旋转变化。`no_phase` 若明显恶化，表明其在该数据/预测跨度上有增量价值。
- **幅度条件**：根据学习周期表改变残差表示的尺度、偏置。`no_amplitude` 识别其是否真正提高预测。
- **输入直连**：直接携带历史信息并降低学习难度。`no_input_skip` 检查其是否是精度主要来源。
- **所有周期条件**：`no_cycle_condition` 使周期表的索引不再影响网络输入，区分“周期模板减法”与“相位条件化”是否必要。

## 如何使用消融结果确定可迁移模块

1. 如果 `no_phase` 影响极小，先研究该支路是否被输入直连掩盖，或在无规律数据中带来过拟合；不要立即增加更强相位网络。
2. 如果 `no_amplitude` 明显恶化，保留条件仿射的功能，研究更合理的**条件估计方式**，而非再叠一层 attention。
3. 如果 `no_template` 改善表现，则检查固定 `Q` 是否在弱周期或周期不稳定片段出现失配；候选机制包括基于历史的动态周期估计、传统平滑或稳健分解。先在验证集测试，不直接在测试集多次择优。
4. 如果 `no_input_skip` 恶化显著，则轻量主干是其基本预测保障，后续只修改周期残差处理；如果删除直连反而改善，需要检查它是否过度依赖近期局部模式。
5. 如果 `no_cycle_condition` 在 ETTm1 和 ETTh1 上表现不同，可以将**数据周期强弱/漂移**作为异质性分析方向。

## 下一阶段研究矩阵

第一层：ETTh1、ETTm1，L96，H96，单随机种子，用于筛选值得追踪的差异；同时存储训练耗时与日志。

第二层：固定同一数据/时段和预测步长，在两个数据集各选最有证据的一个功能开展替换。变体需和消融共享相同的数据处理、训练、验证及测试协议。

第三层：在 H336 和不同随机种子下验证相同现象，补充预测误差随历史波动、周期不稳定程度而变化的条件分析。

注意：**原模型性能持平不是新方法本身的创新证明；必要时研究可以落脚于特定经济/能源数据条件下的新发现。**
