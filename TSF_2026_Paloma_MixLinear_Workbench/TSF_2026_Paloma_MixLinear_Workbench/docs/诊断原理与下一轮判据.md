# Paloma v7 诊断原理与下一轮选择标准

## 一、为什么不直接继续 v7 网络拼接？

v1–v6 已经有多个模块在 ETTh1/ETTm1 的同一试验范围内得到不足1%的小幅增益或退化。尚未知道是：

1. Input Skip 的预测信号压制了其他模块的边际作用；
2. Phase 和 Amplitude 传递的信息高度冗余；
3. 模型主要在少数高波动、模板不匹配或长预测距离条件下存在问题。

这三种机制会指向完全不同的替换件；不能在识别之前继续堆叠 Attention/Head。

## 二、模型中的三个敏感性量

原模型：`Y = Head( MLP(P + A) + S )`，其中 `P=PhaseModulation(X-Q)`、`A=ConditionalFusion(X-Q)`、`S=input_proj(X)`。

- 固定权重关闭某个路径后得到 `Y_minus_path`。变化的 MSE 只反映已经拟合模型的**干预敏感性**，不等于把该模块删掉重新训练后的性能。
- 将 `Head` 最后一层（线性）分解为 `W @ Hidden` 与 `W @ Skip`，分别计算在反标准化尺度上的 RMS。它反映信号强度，但不能解释成相加为100%的贡献，因为它们可能相关或抵消。
- 对当前 MSE 求导得到 `dLoss/dP`、`dLoss/dA`、`dLoss/dS`。这些梯度反映当前位置的局部敏感性，不等于可迁移模块的预期增益。

## 三、条件误差

将验证集历史特征分为低、中、高三个组；同一窗口的未来实际误差用于评价。三种条件分别是历史标准化差分强度、首末四分之一均值差、以及历史序列与周期模板 Q 的失配。还报告七个变量（包括 OT）和四个预测距离分段。

## 四、如何用结果决定下一轮替换？

- 如果验证集 `no_input_skip` MSE 明显更差且 Input Skip RMS 很大，表示当前模型严重依赖输入直连。下一轮应该优先研究**直连与周期分支之间的预测信息互补**，而不是简单加深 Phase 支路。
- 如果 `no_phase`、`no_amplitude` 影响极不对称，则优先检查贡献较低分支是否重复编码，并尝试**同功能模块替换**，而不是再堆一个无监督门控。
- 如果高 `template_mismatch` 组误差明显更高且这一关系在两个数据集都存在，则研究具备**周期表示适配或跨周期信息交换**功能的模型（如 TimeBase、PhaseFormer 的机制），而不是先验确定任何一个会改善。
- 如果高 `historical_volatility` 组误差明显更高，并且某条路径的关闭影响随波动增强，才进入**高噪声条件下的信息选择/局部异常处理**（例如 SEER 一类功能）。
- 如果随预测距离增加 MSE 明显恶化，才考虑**分段未来条件化**，且要避免把若干相同输入的线性 Head 拆开当作创新。

以上都是形成下一轮可验证假设的条件，不是本轮自动得出的事实。不同任务可以存在不一致，也应保留这些差异。
