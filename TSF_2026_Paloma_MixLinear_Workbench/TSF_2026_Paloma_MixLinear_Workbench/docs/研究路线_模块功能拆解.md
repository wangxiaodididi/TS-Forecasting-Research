# 2026 年母体与迁移模块研究备忘录

## 1. Paloma（NeurIPS 2026，作者仓库 2026-10-20 提交）

**模型核心：残差不必是无结构噪声。** 代码入口 `models/Paloma.py::Model.forward(x, cycle_index)`，输入 `[B,T,C]`，输出 `[B,H,C]`。数据通过训练集拟合的 `StandardScaler`，模型内部另做 sample-level mean/std 归一化，最终反归一化。

信息流：

```
X[B,T,C]
 ├── 实例级归一化、转置 [B,C,T]
 ├── 按 cycle_index 索引周期模板 Q、phase、amplitude
 └── Residual = X - Q
      ├── PhaseModulation：cos/sin 两分支 + 投影去相关 + 相位控制旋转 + 残差快捷路
      └── ConditionalFusion：sigmoid(scale) * content + shift
 两分支融合 -> GELU Linear -> 与输入直通 embedding 相加 -> 预测层 -> 反归一化
```

不能随意替换的部分：原始设想的“周期模板 + 条件残差”；移除这部分等于研究另一个模型。优先功能验证：①仅去掉 PhaseModulation，②仅去掉 ConditionalFusion，③删去周期模板 Q（但保留周期输入），④只改变残差信息的结构化表示。模块消融应固定其他配置与随机种子，训练后才报告数值。

适配风险：所谓 phase 条件是**已知周期索引**，不是直接由任意价格周期自动学习。对于低周期强度的能源/经济序列，周期长度或相位误差可能使这个机制失效；先做谱峰强度、周期稳定性、按周期划分误差分析，再考虑把它迁移到新领域。

## 2. MixLinear（ICLR 2026，作者仓库 2026-08-19 提交）

`models/MixLinear.py::Model.forward(x)`：`[B,T,C] -> [B,H,C]`。先减去窗口均值，通过逐通道 Conv1d 平滑并与输入相加，按 period_len 分段。

- TLinear：将段数补到平方数后，用两个因式分解的线性映射处理时间段关系。
- FLinear：沿段维做 FFT，截断 `lpf` 个频率槽位，再用两层复数 Linear、IFFT 预测未来段。
- 融合：`alpha * time_path + (1-alpha) * frequency_path + seq_mean`。注意当前官方 forward 仍有逐 batch 的 shape print，会让训练日志变大。

作者设置不是完全统一：ETTh1 示例 `seq_len=720, period_len=24, lpf=1/2`（视 H 而定）；ETTm1 示例 `seq_len=720, period_len=2, lpf=144`。`seq_len` 必须能被 `period_len` 整除，且 `lpf <= seq_len/period_len`。

适合的单功能研究：时间路径冗余、频域谱截断对非平稳信号的损失、固定线性融合对不同样本的适应性。建议先分别计算 time-only、freq-only 的验证误差及频谱能量覆盖，再选择适当模块；不建议直接添加复杂注意力来替代轻量结构。

## 3. 第一轮“条件能力诊断”，而不是立即缝合

1. 对两模型先完成原始训练复现，验证论文中对应单 horizon 的报告，保存真实 `MSE/MAE/耗时/参数量`。
2. 对每模型统计 `H=96,336`、ETTh1/ETTm1 的逐样本误差，按历史窗口的 `周期强度/局部趋势变化/波动水平` 分组；所有分组阈值仅用训练/验证集决定。
3. 如果原模型在**周期不稳定组**明显退化，优先验证周期状态估计误差；如果在**频谱扩散组**退化，先验证低秩截断的损失；如果不存在系统性短板，不强行提出替换机制。
4. 每次仅改一个功能：baseline -> one-change -> ablation -> 组合（如果确有互补证据），固定测试集直到方案收敛。
5. 正式论文目标仍是“成熟方法的条件改善 + 经济/应用解释”，不能以换零件作为唯一贡献，也不能用测试集成绩调参后仍宣称无偏性能。
